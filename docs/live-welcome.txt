Welcome to ASCII Linux 0.1.
F1: launcher. F2: files. F3: Bash (exit returns to desktop).
F4: system information. F9: text editor. F10: power menu. Esc: back.
F11: processes. F12: network information. Built-in tools stay in the F1 menu.
W from the desktop or F1: ASCII web browser with layout and text views.
Browser: G enters an HTTP/HTTPS address, Tab selects links, Enter follows,
Up/Down and Page Up/Down scroll, Backspace goes back, ] goes forward, R reloads,
X cancels a load, L switches layout/text without reloading, / finds text,
N finds the next match, B bookmarks the page,
M opens bookmarks, and Esc returns to the desktop.
In bookmarks: arrows select, Enter opens, D confirms deletion, R reloads,
M returns to the page.
Standalone: ascii-browser https://example.com
To save it in Apps, use N with name ASCII Browser, command ascii-browser,
and terminal mode t. The built-in browser does not add a user launcher itself.
HTML and plain text are supported, with verified HTTPS and 2 MiB response limits.
Layout uses ASCII boxes, navigation, columns/cards and aligned tables, based on
HTML structure and simple embedded/inline CSS grid/flex hints. Narrow terminals
stack columns. This approximates a site's layout; it is not a full CSS engine.
External stylesheets, JavaScript, image loading, forms and file downloads are
not supported; images use alt-text placeholders. Cookies last only for this session.
Layout search matches within rendered rows; use L for phrases that wrap.
Bookmarks save under the XDG data directory in ascii-linux/browser-bookmarks.json.
Apps: A from the desktop or F1 menu opens your saved launchers, initially empty.
In full Apps, N adds a name, command, optional description and launch mode;
choose g for graphical windows or t for terminal apps. M changes a saved mode.
D removes a launcher after confirmation without uninstalling its program;
R reloads.
I installs from a pasted Bash command, then saves a separate launch command.
Review both commands; Y runs, N/Esc cancels. Installer runs in your home with
pipefail and may ask for sudo. Only exit 0 adds the launcher; failed/interrupted
commands may leave changed files or packages, which are not rolled back.
Arrows/Tab select, Enter launches, / searches names/descriptions/commands,
Esc returns to desktop. Example command: python3 /home/jacob/my-app/main.py
Launch commands run in your home without a shell; quote paths with spaces.
Scripts need executable permission or an interpreter; use bash -lc explicitly
for shell syntax. N only registers; I installs after review. Nothing installs
automatically, and Apps does not scan .desktop files.
Brave official instructions: https://brave.com/linux/
I installer: curl -fsS https://dl.brave.com/install.sh | sh
Launch command: brave-browser. On a host, install curl if missing:
sudo apt install curl. Choose graphical launch mode (g) for Brave.
The live session uses X11/Openbox with a frameless ASCII desktop in xterm.
Regular graphical apps open separate windows while the desktop stays usable.
Alt+Tab switches windows; Super+D returns to the ASCII desktop.
Brave installation/startup remains unvalidated; it is not installed by default.
Launchers save in ${XDG_DATA_HOME:-~/.local/share}/ascii-linux/apps.json;
relative XDG paths use ~/.local/share. JSON entries have id, name, command
(argument list), description and launch_mode (terminal or graphical).
Older entries default to terminal; adding through the Apps UI is recommended.
Wide terminals show a desktop Apps panel; narrow terminals show an Apps strip.
Files: F5 copy, F6 move, F7 mkdir, F8 delete (permanent, confirmation),
N rename, / search filenames, E edit selected file.
Editor: Ctrl+S save, F6 save as, Ctrl+O open, Ctrl+N new, Ctrl+F find,
F5 next match, Ctrl+Z undo, Ctrl+Y redo,
Esc/Ctrl+Q close (confirms unsaved changes).
Processes: / search, S sort, Enter inspect, K confirmed SIGTERM, R refresh.
Network: arrows select, Enter details, R refresh. Connection changes are deferred.
This is a live prototype: changes are not persistent by default.
For recovery use Ctrl+Alt+F2, or edit the boot command to add ascii.safe.
ascii.console starts the ASCII interface without X11. Graphical launchers need
a display; they cannot open windows in this console recovery mode.
There is no disk installer yet. Do not use this prototype for sensitive data.
